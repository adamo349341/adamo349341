## `$ featured_projects`

### 01. DoH Security & Abuse Detection Platform

**Python | scikit-learn | Wireshark | Zeek**

[![Repository](https://img.shields.io/badge/Repository-View_Project-00FF88?style=flat-square&logo=github&logoColor=black)](https://github.com/adamo349341/-DNS-over-HTTPS-DoH-Security-Abuse-Detection-Platform)

A machine-learning-based approach to detecting suspicious DNS-over-HTTPS traffic through behavioral metadata without decrypting encrypted payloads.

- Captured and analyzed controlled network traffic using Wireshark and Zeek.
- Engineered behavioral features including packet sizes, inter-arrival times, flow duration, byte counts and query entropy.
- Developed a Random Forest classification workflow.
- Evaluated six attack categories: C2 beaconing, DNS tunneling, DGA domains, homograph attacks, slow-drip exfiltration and NXDOMAIN flooding.

### 02. AI-Powered DevSecOps Automation

**Python | GitLab API | Docker | Telegram**

A Telegram-controlled automation platform designed to orchestrate and monitor GitLab CI/CD pipelines and security assessments.

- Trigger and monitor GitLab pipelines through Telegram.
- Retrieve job logs and track pipeline execution.
- Integrate SAST, dependency auditing, container vulnerability scanning and secret detection.
- Automate pipeline notifications and security reporting.

### 03. AI-Powered Network Intrusion Detection System

**Python | scikit-learn | Electron | Node.js | MongoDB**

A desktop-oriented network security analysis platform combining machine learning with SOC/SIEM-inspired workflows.

- Random Forest model trained on CIC-IDS flow data.
- CSV and PCAP analysis with live-capture support.
- Dashboard-based alert triage and SIEM-compatible JSONL export.
- Optional AI-assisted alert explanations using OpenRouter.
